# Day 28 - To-Do List with Local Storage 

Today I improved my to-do list app by saving tasks in local storage.

## Features Added
- Add tasks
- Delete tasks
- Save tasks after refresh
- Load saved tasks automatically

## Concepts Used
- localStorage
- JSON.stringify()
- JSON.parse()
- window.onload

## About
This project makes the to-do list more realistic by keeping tasks saved even after page refresh.
