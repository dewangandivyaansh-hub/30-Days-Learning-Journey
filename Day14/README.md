# Day 14 - Air Quality Analyzer

Today I built an air quality analyzer using Python.

## Features
- Add AQI data for cities
- Categorize air quality (Good, Moderate, Unhealthy, etc.)
- View all records
- Find most polluted city
- Save and load data from file

## Concepts Used
- Functions
- Lists
- Dictionaries
- File Handling

## About
This project analyzes air quality data and helps identify pollution levels in different cities.
