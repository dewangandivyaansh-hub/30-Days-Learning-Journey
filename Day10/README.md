# Day 10 - Mini Project (Student Management System) 

Today I built a file-based student management system using Python.

## Features
- Add student records
- View all students
- Search student by roll number
- Update student details
- Delete student record
- Save data to file

## Concepts Used
- Functions
- Lists
- File Handling

## About the Project
This program stores student data in a file and allows managing records through a menu-driven system. It simulates a basic real-world database system.
